# Анімація спрайтів, хітбокси та UI в p5.js

Цей проєкт виконує Завдання 4 (Варіант А) з розробки інтерактивного медіа. 
Анімації персонажа реалізовано процедурним шляхом через малювання векторних форм для трьох станів: Idle (4 FPS), Walk (11 FPS) та Run (15 FPS). 
Перемикання анімацій здійснюється за допомогою гарячих клавіш 1, 2 та 3 на клавіатурі. 
У проєкті додано інтерактивний UI: слайдер масштабування (Scale від 0.5x до 2.5x) та кнопку відображення по горизонталі (Flip). 
Під кожен стан анімації налаштовано адаптивний прямокутний Hitbox, який динамічно змінює свої розміри (наприклад, звужується за висотою під час нахилу при бігу). 
Для подальшого покращення можна додати імпорт зовнішніх PNG-спрайтшітів із прозорим фоном та фізику гравітації для стрибка.
